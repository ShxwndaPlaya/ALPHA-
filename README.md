🚀 About The Project

ALPHA LAN is a local network (LAN) ecosystem built for schools, coding clubs, and developers to:

💬 Chat like WhatsApp
💻 Code in a multi-language IDE
🛍️ Share and trade projects
🌐 Simulate websites
🧠 Collaborate and learn together

All without Internet — just LAN magic ⚡

⚡ Core Features
💬 Chat System

Real-time LAN messaging

Group & private chats

Code snippet sharing with syntax highlighting

Voice/video calls via WebRTC

Custom themes & chat UIs

Emoji, reactions, file sharing

💻 Built-in IDE & Compiler

Multi-language editor (Python, C, C++, Java, JS, etc.)

Auto-completion, error linting, and syntax highlighting

Terminal-like console output

Multi-user real-time collaboration

Local sandbox execution

Split-view editing

🛍️ Code Shop / Marketplace

Share or download others’ code

Ratings, comments, and reviews

“Fork” projects and remix them

Earn badges and XP for sharing

Reputation system & leaderboard

🌐 Web Simulator

Live HTML/CSS/JS preview (like CodePen)

Console & device view

Share web demos over LAN

Save & export mini-sites

🧠 Gamified Learning

Quizzes, challenges & hackathons

XP system & developer levels

AI Tutor (code explainer)

Achievements (“Night Coder”, “Bug Slayer”)

🧰 Admin & Utility

Admin dashboard & analytics

Role-based access (students/teachers/admin)

Broadcast announcements

User moderation & logs

🧩 Tech Stack
Layer	Technology
Frontend	React + TailwindCSS + Vite
Backend	Node.js + Express.js
Database	SQLite / PostgreSQL
Real-time	Socket.io
Compiler	Judge0 API / Docker Sandbox
Auth	JWT (JSON Web Tokens)
UI Framework	shadcn/ui + lucide-react icons
🗂️ Project Structure
ALPHA-/
├── client/         # React Frontend
│   ├── components/ # UI Components (Chat, IDE, Shop, etc.)
│   ├── pages/      # Pages (Home, Profile, Admin, etc.)
│   └── styles/     # Tailwind + global styles
│
├── server/         # Node.js Backend
│   ├── routes/     # API Endpoints
│   ├── controllers/# Logic for routes
│   ├── models/     # Database models
│   └── utils/      # Helper functions & compiler logic
│
└── database/       # SQLite/PostgreSQL setup

⚙️ Setup & Run
# clone the repo
git clone https://github.com/ShxwndaPlaya/ALPHA-.git

# enter project folder
cd ALPHA-

# install dependencies
cd server && npm install
cd ../client && npm install

# start both servers
npm run dev


🧠 Pro Tip:
You can use local IP (e.g. 192.168.x.x:5173) to connect all computers on the same Wi-Fi or LAN.
